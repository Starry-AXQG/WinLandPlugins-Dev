# 声枢 (MediaDeck)

**作者**：Starry-AXQG · **插件 ID**：`media-deck` · **适用宿主**：WinIsland (WinLand) ≥ 2.4.0

一站式灵动岛媒体与音频控制中枢：多媒体实例切换、同步三行歌词、音频响应背景流光、音频输出设备快切、Windows 音量合成器、Windows 空间音效、定时暂停与蓝牙耳机接入提醒。

---

## 核心特性

- **双形态音频响应流光**：胶囊形态与展开卡片形态均内置三层径向极光光晕，随当前输出设备的实时左右声道与主音频电平呼吸与漂移（无需麦克风权限）。
- **多实例管理与平滑切换**：
  - 同时管理所有活跃的系统媒体会话（SMTC）及未接入 SMTC 的兜底播放器（如网易云音乐）；
  - 按“最近播放”自动维护实例顺序（新实例插入首位，暂停转播放时自动与首位交换）；
  - 悬停大岛卡片时支持 **鼠标滚轮**、**按住左右滑动** 或 **点击顶部居中圆点指示器** 触发平滑滑入动画切换实例。
- **来源识别与窗口激活**：
  - 基于 Windows Shell `FOLDERID_AppsFolder` 原生解析 Firefox / Zen 浏览器哈希 AUMID、Spotify 等应用真实名称与高清图标；
  - 点击卡片左上角应用图标即可激活对应播放器主窗口；若该窗口已处于激活状态，再次点击将闪烁窗口与任务栏图标提醒用户。
- **卡片内音频输出快切**：
  - 右上角自动区分 **HDMI / 显示器音频**、**耳机（蓝牙设备带蓝色蓝牙角标）** 与 **扬声器** 图标；
  - 点击在卡片内展开可滚动的输出设备切换菜单，不超出卡片边界、不引发卡片失焦收起。
- **三列聚光卡（点击卡片空白处展开）**：
  - **顶部**：定时暂停（15 / 30 / 45 / 60 分钟倒计时自动暂停媒体）；
  - **左列（音频输出设备）**：区分 HDMI、蓝牙耳机、有线耳机与扬声器，一键零卡顿切换；
  - **中列（Windows 音量合成器）**：显示每个发声程序的真实图标，图标右上角挂载动态发声波形 / 静音状态角标（点击图标一键静音，悬停提示“静音该应用”），支持独立调节各程序音量；
  - **右列（Windows 空间音效）**：枚举并切换当前设备支持的 Windows Sonic、Dolby Atmos for Speakers / Headphones、DTS Headphone:X。
- **动态优先级**：支持播放时自动提升优先级占据小岛胶囊，全部暂停超时后自动降低优先级让位给其他插件。
